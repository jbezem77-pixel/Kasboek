# Kasboek

Boekhouding voor een zzp'er: facturen, kosten en bonnen, uren, ritten, activa, btw-aangifte, belastingpotje en bankafschriften.

**Je gegevens staan alleen op je eigen telefoon.** Deze map bevat alleen het programma, geen administratie. Er gaat niets naar een server, behalve als je zelf een API-sleutel invult om bonnen te laten uitlezen (dan gaat alleen die bon naar Anthropic).

## Installeren
1. Open de app-link in Chrome op je telefoon.
2. Tik op ⋮ › **App installeren** (of **Toevoegen aan startscherm**).

## Back-up
Ga naar **Meer › Export & back-up › Back-up maken** en kies **Drive**. De app herinnert je eraan als je langer dan een week geen back-up hebt gemaakt.

## Updates
Een nieuwe versie wordt pas actief als je in de app op **Bijwerken** tikt. Je gegevens blijven daarbij staan.
